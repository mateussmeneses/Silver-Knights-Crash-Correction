[Default Game Controls]

[Ground]
Direction key		: Lock OFF- Right/Left turns. Forward/Backward moves.(Dash is pushed twice)
			: Lock ON - Right/Left strafe around target. Forward/Backward moves.(Dash is pushed twice)]
N (Pad 2 button)	: Lock ON/OFF (Cancel is pushed twice)

N (Pad 2 button)	: Lock ON Enemy. After lock on + N: Enemy's shot 
			: Press N twice for cancel lock on on any target
N + Right/Left Dir. key : Change lock-on target
B (Pad 4 button)	: Main shooting / Sword attack.
V (Pad 3 button)	: Sub shooting / Heavy sword attack.
C (Pad 1 button)	: Flight (Sudden rise is pushed twice)
X (Pad R1 button)	: Guard
Z (Pad L1 button)	: Option / Modification
F (Pad R2 button)	: Help message.
D (Pad L2 button)	: Spare message.

[Space]
Direction key		: Lock OFF- Front/Back/Right/Left turns.(Dash is pushed twice)
			: Lock ON - Front/Back/Right/Left moves around the target.(Dash is pushed twice)
Direction key+C(Pad 1)	: Up/Down/Right/Left moves.
C (Pad 1 button)		: This without a direction key is front movement.
			  (Urgent evacuation is pushed twice)

<Others are the same as [Ground]>

[Flight type]
Direction key	: Turns
N (Pad 2 button)	: Not used (Automatic lock if enemy entering the circle)
B (Pad 4 button)	: Main shooting
V (Pad 3 button)	: Sub shooting
C (Pad 1 button)	: Acceleration
X (Pad R1 button)	: Right yaw
Z (Pad L1 button)	: Left yaw
F (Pad R2 button)	: Help message.
D (Pad L2 button)	: Spare message.
X + Z		: Modification is canceled.

[Watch mode]
Direction key	: Turns
N (Pad 2 button)	: Not used
V (Pad 3 button)	: Back
C (Pad 1 button)	: Mode change
X (Pad R1 button)	: Right moves
Z (Pad L1 button)	: Left moves

[Language change]

This game acquires the language code from your OS.
The setting file .ini corresponding to this language code is read, and displayed in the game.

For example, it is as follows.

1033.ini : English
1036.ini : French
1041.ini : Japanese
3076.ini : Hong Kong

When you make a new language file, please copy the '1033.ini' file and rewrite it
in your language code of your own country.
The language code is displayed on the lower right of the title screen.
