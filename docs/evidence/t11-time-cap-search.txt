## Reading the result

Total code sites disassembled: 12

- A hit inside `cmp`/`sub` followed by `jae`/`jbe`/`jb`/`ja` is a plausible limit test.
- A hit in `.rdata`/`.data` is a stored value, not a comparison - it would have to be
  loaded first, so look for the `mov`/`fld` that references it.
- **Absence is also informative**: if no immediate 1800000 or 1800 appears in code,
  the cap is probably computed (start tick vs current tick against a stored limit) or
  encoded as a float constant that this search did not guess correctly. That would
  not weaken the runtime finding, only leave its mechanism unnamed.
- This tool does NOT prove which site is the cap. `run-51` and a targeted breakpoint
  experiment would. Treat any single hit as a candidate, not a conclusion.
